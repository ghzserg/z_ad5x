# Правила работы с Z-Mod

Перед анализом и изменениями прочитать общий [AGENTS.md](https://github.com/ghzserg/zmod/blob/main/AGENTS.md) из актуальной ветки `main` репозитория `ghzserg/zmod`. Эти правила обязательны и для данного репозитория.

Если файл недоступен, сообщить пользователю и запросить его содержимое, не подменять правила предположениями.

Не править вручную сгенерированные файлы `translate/`: их исходники находятся в `ghzserg/base`. При переносе общих изменений в `z_ad5x` и `z_c5pro` соблюдать правила соответствующих репозиториев.
